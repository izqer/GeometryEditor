# GeometryEditor

Небольшой редактор геометрических фигур на C#. Сделан в рамках тестового задания, где нужно было продемонстрировать работу с ООП.

Изначально задача была просто в отображении фигур, но решил добавить возможность их создания и редактирования через интерфейс.

## Что реализовано

- Создание круга, квадрата, прямоугольника и треугольника.
- Изменение координат, размеров и цвета.
- Выделение фигур мышкой или через список.
- Перемещение фигур по холсту.
- Изменение размеров мышкой за маркер.
- Удаление созданных фигур.
- Проверка введённых значений и вывод ошибок.

Квадрат сделан через прямоугольник с ограничением на равные стороны. Треугольник пока только равнобедренный.

## Структура проекта

В решении три проекта:

- `GeometryEditor.Core` — классы фигур и общая логика редактора.
- `GeometryEditor.Wpf` — интерфейс на WPF.
- `GeometryEditor.Avalonia` — интерфейс на Avalonia UI.

Логика фигур и управления ими общая для обеих версий. Отрисовка и работа с мышью реализованы отдельно, поскольку WPF и Avalonia используют разные элементы интерфейса.

## ООП

Основой фигур является абстрактный класс `Figure`. От него наследуются `Circle`, `RectangleFigure` и `Triangle`.

Общие свойства, такие как координаты и цвет, находятся в базовом классе. Размеры и ограничения задаются уже в конкретных фигурах.

Для определения попадания точки внутрь фигуры используется метод `ContainsPoint()`. Каждая фигура реализует его по-своему.

Для интерфейса используется MVVM и `CommunityToolkit.Mvvm`. Созданные фигуры хранятся в `ObservableCollection`, а основные действия вызываются через команды.

## Технологии

- C# / .NET 10
- WPF
- Avalonia UI
- CommunityToolkit.Mvvm

## Запуск

1. Открыть `GeometryEditor.slnx` в Visual Studio.
2. При необходимости восстановить NuGet-пакеты.
3. Выбрать запускаемый проект: `GeometryEditor.Wpf` или `GeometryEditor.Avalonia`.
4. Собрать и запустить проект.

Для WPF требуется Windows. Для сборки используется .NET 10 SDK.

## Что пока не реализовано

- Сохранение и загрузка созданных фигур.
- Поворот фигур.
- Произвольные треугольники с редактированием каждой вершины.

При закрытии приложения созданные фигуры не сохраняются.
