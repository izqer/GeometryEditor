# GeometryEditor

Небольшой редактор геометрических фигур на C#. Проект разрабатывается в рамках тестового задания с целью продемонстрировать применение объектно-ориентированного программирования.

Основная идея — реализовать работу с геометрическими фигурами, включая их создание, отображение, редактирование и удаление.

## Технологии

- C# / .NET 10
- WPF
- Avalonia UI
- MVVM (CommunityToolkit.Mvvm)

## Структура решения

Проект разделён на три части:

- **GeometryEditor.Core** — общая библиотека классов. Здесь будет находиться логика работы с геометрическими фигурами, не зависящая от конкретного UI-фреймворка.
- **GeometryEditor.Wpf** — реализация интерфейса на WPF.
- **GeometryEditor.Avalonia** — пробная реализация интерфейса на Avalonia UI.

Две реализации интерфейса используются для демонстрации возможности работы с одной библиотекой через разные UI-фреймворки.

## Возможности

Планируется реализовать:

- Создание круга, квадрата, прямоугольника и треугольника.
- Настройку положения, размеров и цвета фигур.
- Вывод созданных фигур на рабочую область.
- Выбор и редактирование существующих фигур.
- Перемещение и изменение размеров фигур мышью.
- Удаление фигур.
- Проверку введённых параметров и вывод сообщений об ошибках.

## Текущее состояние

На данный момент подготовлены интерфейсы WPF и Avalonia UI. Реализованы основные панели управления, рабочая область с тестовыми фигурами и выбор цвета.

Логика работы с фигурами и общая библиотека классов находятся в разработке.

## Запуск

Для сборки понадобится Visual Studio 2026 с установленным .NET 10 SDK и необходимыми компонентами разработки настольных приложений.

1. Открыть решение `GeometryEditor`.
2. Восстановить NuGet-пакеты.
3. Выбрать запускаемый проект `GeometryEditor.Wpf` или `GeometryEditor.Avalonia`.
4. Запустить приложение.

Проект находится в разработке.
